# Arcana Privada — MVP Android

Prototipo empresarial de una aplicación de tarot para Android construido con Expo / React Native.

## Incluido
- Inicio comercial con accesos rápidos.
- Selector de imágenes desde la galería.
- Tirada interactiva de 3 cartas.
- Central de consultas privadas.
- Vista de Tarot en vivo preparada para integrar videollamadas.
- Agenda y reservas.
- Lógica separada para tiradas y precios.
- Pruebas unitarias de lógica de negocio.

## Ejecutar
1. Instalar Node.js y Expo.
2. En la carpeta del proyecto: `npm install`.
3. `npm run android` para abrir en Android/Expo Go.
4. `npm test` para ejecutar las pruebas incluidas.

## Próxima fase de producción
Conectar autenticación y base de datos; almacenamiento privado de imágenes; chat en tiempo real; videollamada; pagos; notificaciones push; panel web administrativo; políticas de privacidad y eliminación de cuenta; publicación en Google Play.

La marca, textos, precios y mazos están planteados para poder reemplazarse sin rehacer toda la aplicación.
